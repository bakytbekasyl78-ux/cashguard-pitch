# CashGuard — ForteBank / Datathon 26

Отдельный сайт для питча: задача, ML pipeline, результаты, работающий продукт, нормативные основания и команда. Оригинальная пиксельная графика, семь глав, обычный просмотр и режим выступления.

## Просмотр

GitHub Pages: публикуется ветка `main`, папка `/ (root)`. Сборка не требуется; `.nojekyll` сохраняет статический сайт без преобразований Jekyll.

Локально: `python3 -m http.server 8010 --bind 127.0.0.1`, затем http://127.0.0.1:8010/ .

Режим питча: Alt+P (Mac Option+P), стрелки/пробел — главы, Escape — выход. Таймер на четыре минуты запускается отдельно.

## Результаты и данные

86% обнаружения и 80% классификации сообщены ML-командой. Размер выборки, определения метрик и независимость оценки пока не указаны. Это не независимая валидация.

Изображения продукта показывают сохранённую проверку на синтетическом трёхсекундном MOV. Пример 2,65 с подтверждает этот единичный путь интеграции, а не общий SLA или качество на банковских видео.

Сайт не содержит ключей, приватного видео, весов моделей и backend. Ссылка на действующий анализатор открывает отдельный сервис, где вводится ключ доступа.
